# Trazify
A professional image-to-FreeRiderHD track converter with advanced algorithms and optimized performance. Enhanced version with improved UI/UX, real-time previews, and support for complex images.

## Features

- **Real-time Preview** - See your track layout as you adjust spawn points and zoom levels
- **Advanced Image Processing** - Intelligent color quantization with support for all FreeRiderHD object types
- **Optimized Performance** - Handles large and complex images with adaptive downsampling
- **Professional Interface** - Golden ratio-based design with smooth animations and intuitive controls
- **Collapsible Features Panel** - Organize your workspace with toggleable object types
- **Dynamic Canvas** - Smooth drag-and-drop positioning with visual crosshair guidance

## Usage

1. Upload an image (PNG, JPG, etc.)
2. Adjust the spawn point position on the canvas
3. Select which object types to include in the Features panel
4. Press 'Generate' to create your track code
5. Copy the code and paste it into FreeRiderHD!

## Technical Details

- Built with vanilla JavaScript for maximum compatibility
- Uses Canvas API for real-time rendering
- Implements intelligent color matching for precise object placement
- Adaptive resolution handling for images up to 4000x4000+ pixels
